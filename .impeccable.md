# .impeccable.md

Дизайн-контекст проекта MacroStress-Agent. Файл читается перед любой работой над интерфейсом
(`ui/web`, отчёт на выпуск). `ui/web` — единственный интерфейс. Подписи типов активов, их полей,
рядов и метрик приходят с сервера (`GET /v1/asset-types`), а не пишутся в интерфейсе.

## Design Context

### Users

**Первичный пользователь — кредитный аналитик банка.** Работает при дневном свете в офисе, на
втором экране у него PDF нормативного акта и выгрузка по эмитенту. Его задача — не «посмотреть
дашборд», а **сверить**: действительно ли из этого пункта постановления следует такой сдвиг
EBITDA, откуда взялся мультипликатор, кто и когда внёс допущение.

**Вторичный — риск-менеджер / член комитета.** Приходит принять решение по отчёту. Ему нужны
вывод, интервал и основание — так, чтобы поставить подпись под документом, который потом могут
поднять при проверке.

**Работа, которую они выполняют:** превратить текст качественного события в защищаемую
количественную позицию по портфелю. Результат живёт не на экране, а в утверждённом отчёте,
за который отвечает человек.

**Три следствия из предметной области:**

1. Результат — **интервал P5/P50/P95**, а не число. Интерфейс, показывающий одно значение,
   врёт о продукте.
2. У каждого числа есть **происхождение** (документ / историческая оценка / допущение аналитика
   с автором и датой). Оно доступно по клику прямо у числа, а не спрятано на отдельном экране.
3. **Публикация — только после утверждения человеком** (кодекс этики ИИ на финансовом рынке
   Банка России, требование пересматриваемости решений). Утверждение — самое ответственное
   действие в продукте.

### Brand Personality

**Три слова: понятный, подотчётный, спокойный.**

- **Понятный.** Обычный продуктовый интерфейс, узнаваемый с первого взгляда: шапка, список,
  вкладки, таблицы, боковые панели, окна подтверждения. Никаких собственных метафор вместо
  привычных элементов. Человек не должен учиться интерфейсу — только предметной области.
- **Подотчётный.** Каждое утверждение на экране готово к вопросу «откуда». Система не
  изображает уверенность, которой у неё нет: неопределённость показана честно и рядом с числом.
- **Спокойный.** Ничего не мигает и не требует внимания без причины. Живым выглядит только то,
  что действительно идёт: этап расчёта.

**Голос интерфейса:** русский, деловой, без канцелярита, без маркетинга и без внутреннего
жаргона разработки. Объект работы называется «стресс-тест». Служебные коды (`watchlist`,
`pd_uncalibrated`, `LOAN-MACHINERY-icr`, `RECYCLING-FEE`) не выводятся голыми: либо переводятся, либо, если это
часть подписываемого текста, сопровождаются пояснением. Кнопка называется тем, что делает.

### Aesthetic Direction

**Направление: зрелый продуктовый интерфейс, а не документ и не дашборд.** Референс — рабочие
инструменты банков и SaaS для профессионалов: светлая тема, белые поверхности на светло-сером
фоне, тонкие границы, чёткая типографика, таблицы с выровненными числами.

**Цвет — разведение бренда, действия и риска.**

- **Красный МТС `#E30611`** — только айдентика и утверждение: знак в шапке, полоса над шапкой,
  кнопка «Утвердить и опубликовать», штамп утверждённого отчёта. **Никогда** как цвет ошибки,
  статуса, ряда графика или подсветки строки.
- **Сине-стальной `#2D5F87`** (шкала Mantine `steel`) — всё интерактивное: основные кнопки,
  ссылки, выбранное состояние, числа с происхождением.
- **Статусы** — светлые бейджи, у каждого иконка и текст: идёт — синий, ждёт действия —
  жёлтый, завершён — зелёный, остановлен или отклонён — серый с ✕. Проблемы и нарушения —
  оранжевые плашки. Заголовки плашек тёмные: цвет несут иконка и фон.
- **Тяжесть риска** (уровни low…critical, нарушенный ковенант) несут слово, знак и вес
  начертания; цвет никогда не единственный носитель.

**Типографика.** Golos Text (Paratype, кириллица-first, SIL OFL) для всего интерфейса, из
собственной сборки — никаких обращений к внешним CDN: данные портфеля не покидают периметр
банка. Числа — `tabular-nums`, выравнивание по правому краю. Моноширинный системный — только
для машинных идентификаторов (номер стресс-теста, хеши).

**Композиция.** Шапка (стресс-тесты, портфели, какая LLM работает) → список стресс-тестов с
блоком «Ждут вашего действия» → страница стресс-теста: заголовок события, шкала этапов, одна
плашка «что дальше», вкладки «Сценарий и граф / Активы / Портфель / Отчёт / Источники данных /
Вызовы LLM и MCP». «Портфели» — список и редактор своего портфеля; каждое введённое число —
допущение аналитика с автором и датой. Подробности открываются
на месте: связь графа и актив — в боковой панели, решение — в окне подтверждения. Карточки
группируют смысловые блоки; ряда одинаковых KPI-плиток нет.

**То, что запомнят.** Интервал P5–P95 как полоса на общей для столбца шкале рядом с медианой:
интервалы активов сравниваются глазом без отдельного графика. Эта полоса — данные, а не
декор; прочие «миниграфики для солидности» не добавляются.

**Анти-референсы.** Сетка одинаковых KPI-карточек, светофоры и бублики; «ИИ-продукт» с
фиолетовыми градиентами, glassmorphism и иконкой над каждым заголовком; трейдинг-терминал с
чёрным фоном и неоном; немодифицированный Streamlit и формы без иерархии; интерфейс,
оформленный под печатный документ, со своими метафорами вместо привычных элементов.

### Design Principles

1. **Число без происхождения не показывается.** Числа отчёта открывают шаги расчёта и
   источники по клику; если происхождения нет, показана причина.
2. **Интервал важнее точки.** P5/P50/P95 показываются вместе. Одиночное число допустимо только
   там, где оно детерминировано (идентификатор, дата, количество, сумма под риском).
3. **Красный принадлежит бренду и подписи, не тревоге.**
4. **Одно действие вперёд.** На каждом шаге видно, чего ждёт стресс-тест и от кого; если
   действие ваше — кнопка с глаголом ведёт прямо к нему.
5. **Утверждение — самый весомый момент.** Видно, чьим именем подписывается, до нажатия;
   три исхода разного веса; возврат и отклонение без причины невозможны.

## Технические ограничения

- **Хост — React SPA** в `ui/web` (Vite, TypeScript, Mantine, TanStack Query, React Flow).
  Сборку `ui/web/dist` раздаёт сам FastAPI с того же адреса, что и API. Тема — `src/theme.ts`
  и `src/styles.css`.
- **Язык — русский.** Подписи и словари — `ui/web/src/lib/labels.ts`, форматирование чисел —
  `ui/web/src/lib/format.ts`.
- **Доступность: WCAG 2.2 AA** (4.5:1 для текста, 3:1 для элементов управления), цвет никогда
  не единственный носитель состояния, `prefers-reduced-motion` соблюдается.
- **Движение сдержанное:** стандартные переходы Mantine; анимируется только смена состояния.
