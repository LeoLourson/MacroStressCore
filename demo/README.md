# Демо-каталог

| Папка | Что в ней |
|---|---|
| `portfolios/` | Заголовки портфелей: `{"portfolio": {...}}` без участников, инструментов и позиций |
| `snapshots/` | Заголовки снимков данных без `items` |
| `events/` | События каталога, по файлу на событие (с `mock_answer` для профиля `mock`) |
| `pilot/` | Историческое событие `HIST-MORTGAGE-2023-12`: `event.json` и его источники `sources.json`; читает `demo/pilot.py` |
| `pilot-afk/` | Рабочая папка пилота АФК «Система»: котировки, расчёт бет, сверка с фактом; из неё собирает файлы каталога `build_pilot_afk.py` |
| `pilot-etalon/` | Рабочая папка пилота «Эталон»: отчётность, котировки, данные проекта, сверка с фактом; из неё собирает файлы каталога `build_etalon.py` |

Части портфелей и снимков лежат в плагинах, под тем же именем файла:
`src/msa/plugins/<id>/demo_data/portfolios/<portfolio_id>.json` (`parties`, `instruments`,
`positions`) и `src/msa/plugins/<id>/demo_data/snapshots/<snapshot_id>.json` (`items`).
Заголовок и части сводит `demo/catalog.py`: части читаются в порядке плагинов реестра,
одинаковая запись из двух плагинов допустима, разные записи под одним идентификатором — ошибка.
Плагин может принести и собственный заголовок портфеля или снимка, которого нет в ядре.

Сгенерированные файлы пишет `python -m demo.build_catalog`; `--check` сверяет их без записи.
