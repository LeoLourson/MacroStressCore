# Реализации сценария

Сценарий — набор параметров $k = 1, \dots, d$, каждый со своим распределением $F_k$.
Платформа один раз на стресс-тест строит совместные реализации параметров, и все позиции
считаются на них. Номер реализации общий для всех позиций, поэтому потери позиций можно
складывать внутри одной реализации (страница «Портфельный срез»).

## Распределения параметров

| Вид | Параметры | Квантильная функция $F^{-1}(u)$ | Центральное значение $c$ |
|---|---|---|---|
| точка | $v$ | $v$ | $v$ |
| треугольное | $a \le m \le b$, $a < b$ | обратная к треугольной функции распределения | $m$ |
| равномерное | $a < b$ | $a + (b - a)u$ | $(a + b)/2$ |
| усечённое нормальное | $\mu$, $\sigma > 0$, $a < b$ | нормальное $N(\mu, \sigma^2)$, усечённое к $[a, b]$ | $\mu$ |
| логнормальное | $\mu$, $\sigma > 0$ — параметры логарифма | $\exp(\mu + \sigma \Phi^{-1}(u))$ | $e^{\mu + \sigma^2/2}$ |
| эмпирическое | выборка $s_1 \le \dots \le s_n$ | $s_{i}$, $i = \min(\lfloor u n \rfloor + 1, n)$ | медиана выборки |

Центральное значение — управленческий сценарий, по нему считается центральная оценка
позиции. Это не среднее распределения: у треугольного это мода, у усечённого нормального —
$\mu$ до усечения. Если аналитик задал центральное значение явно, берётся оно.

## Квазислучайные точки

Точки берутся из $R$ независимо перемешанных сетей Соболя по $N = 2^m$ точек размерности $d$.
По умолчанию $N = 8192$ и $R = 8$; меньше восьми реплик платформа не принимает. Сеть
реплики $r$ перемешивается генератором с зерном $(\text{seed}, r)$, столбцы идут в
алфавитном порядке имён параметров. Получаем точки $u_{rj} \in [0, 1]^d$, где
$j = 1, \dots, N$.

## Зависимость параметров

Если в сценарии есть корреляционная матрица $C$, точки проходят через гауссову копулу:

$$
u'_{rj} = \Phi\left(\Phi^{-1}(u_{rj}) L^{\top}\right), \qquad L L^{\top} = C .
$$

$L$ — множитель Холецкого. Матрица должна быть симметричной, с единицами на диагонали и
положительно определённой; иначе сценарий отклоняется, молча её не исправляют. Перед
$\Phi^{-1}$ точка ограничивается отрезком $[\epsilon, 1 - \epsilon]$, $\epsilon = 2^{-53}$.

Значение параметра в реализации:

$$
x_{rjk} = F_k^{-1}\left(u'_{rjk}\right).
$$

## Собственные потоки

Две величины разыгрываются не из общей сети, а из отдельного потока для каждого субъекта:

- собственный шок субъекта (например, остаточная доходность акции), который объявляет модель
  позиции;
- неопределённая эластичность ребра графа события.

Поток задаётся ключом: зерно стресс-теста и имя субъекта или ребра. Он стратифицирован: в
реплике $r$ точка $j$ попадает в свой интервал длины $1/N$,

$$
u_{rj} = \frac{\pi_r(j) + v_{rj}}{N},
$$

где $\pi_r$ — случайная перестановка чисел $0, \dots, N-1$, а $v_{rj}$ равномерно на $[0, 1)$.
Собственный шок со стандартным отклонением $\sigma$ равен $\sigma \Phi^{-1}(u_{rj})$,
эластичность ребра — $F_e^{-1}(u_{rj})$. Поток не зависит от того, какие ещё позиции есть
в стресс-тесте и в каком порядке они считаются.

## Идентичность набора

Набор реализаций идентифицирует `scenario_id` — хеш распределений, корреляций, числа точек
и реплик, зерна, даты оценки, горизонта, графа события, версий факторов и самих значений
реализаций. Результаты с разными `scenario_id` в один срез не складываются.
