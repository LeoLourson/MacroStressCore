# Вклады Шепли

Вклад раскладывает изменение результата позиции по игрокам: каналам графа или факторам,
которые выбирает модель плагина. Это разложение выхода модели, а не доказательство
причинной связи.

## Игра

Игроки $M$, $m = \lvert M \rvert$. Значение коалиции $v(S)$ — полный пересчёт модели на
центральном сценарии, в котором активны только игроки из $S$, а остальные шоки равны нулю.
Пустая коалиция — базовый расчёт, поэтому объясняемый эффект равен $v(M) - v(\varnothing)$.

## Точный расчёт

При $m \le 8$:

$$
\phi_i = \sum_{S \subseteq M \setminus \lbrace i \rbrace}
\frac{\lvert S \rvert ! \thinspace (m - \lvert S \rvert - 1)!}{m!}
\left(v(S \cup \lbrace i \rbrace) - v(S)\right).
$$

Проверяется свойство эффективности:

$$
\sum_{i \in M} \phi_i = v(M) - v(\varnothing).
$$

Если остаток больше $10^{-9}$, результат получает флаг `shapley_not_efficient`.

## Расчёт по перестановкам

При $m > 8$ вклад оценивается средним приростом по случайным порядкам игроков. Перестановки
берутся пачками по 64, не больше 20 000; значение каждой коалиции считается один раз.
После каждой пачки для каждого игрока считается полуширина $1.96 \cdot \hat\sigma_i / \sqrt{n}$ по $n$ приростам. Расчёт останавливается,
когда все полуширины не больше

$$
\max\left(10^{-3}, \thinspace 0.01 \max\left(\lvert v(M) - v(\varnothing) \rvert, s\right)\right),
$$

иначе результат получает флаг `shapley_not_converged`. Эффективность здесь проверяется с
допуском $10^{-3}$.
