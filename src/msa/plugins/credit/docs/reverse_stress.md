# Обратный стресс-тест

Обратный стресс-тест ищет, во сколько раз нужно усилить событие, чтобы ковенант был
нарушен. Направление усиления — часть ответа, а не скрытое допущение.

## Направление

Направление $d$ — центральные значения параметров сценария, которые шокируют заёмщика.
Сценарий масштабируется вдоль него:

$$
x(\lambda) = \lambda d, \qquad 0 \le \lambda \le \lambda_{\max} .
$$

$\lambda = 1$ — утверждённый сценарий. Верхняя граница не даёт относительному шоку дойти до
$-100\%$:

$$
\lambda_{\max} = \min\left(5, \thinspace \min_{k: \thinspace d_k < 0} \frac{0.999}{-d_k}\right),
$$

где минимум берётся по относительным параметрам. Если $\lVert d \rVert = 0$ (сценарий с
центром в нуле), направления нет, и граница не ищется.

## Поиск

Метрика ковенанта $g(\lambda)$ — её значение в первый месяц проверки на центральном графе.

1. Если условие нарушено уже при $\lambda = 0$, ответ $\lambda^{\ast} = 0$.
2. $g$ считается на сетке из 65 точек $\lambda_i = i \lambda_{\max} / 64$. Если условие нигде
   не нарушается, ответ «не найдено на допустимом отрезке».
3. Берётся первый отрезок $[\lambda_i, \lambda_{i+1}]$, на котором условие переходит из
   выполненного в нарушенное.
4. Если скачок $g$ на этом отрезке не больше четверти размаха $g$ по сетке, $\lambda^{\ast}$
   — корень $g(\lambda) = \theta$ методом Брента с точностью $10^{-10}$. Иначе граница —
   разрыв: ответ — сам отрезок, флаг `discontinuous_boundary`.

Если $g$ немонотонна, ответ — первое пересечение, и рядом перечислены все последующие; ни
одно не называется глобальным минимумом (флаг `non_monotonic`). Шок на границе —
$\lambda^{\ast} d$.
