# Плагин `market`: общие рыночные объявления

Базовый плагин семейств, которые оцениваются по рынку: сейчас акции, дальше фонды,
товары и производные инструменты. Версия 1.0.0; SDK `>=1.0,<2.0`. От него разрешено
зависеть другим плагинам (исключение в контракте независимости плагинов `lint-imports`).

| Что объявлено | Значения |
|---|---|
| Фактор | `market.fx`: логарифмическое изменение курса пары `CCY/BASE` к концу горизонта (`scope="currency_pair"`) |
| Срез | `market.pnl`: потери стоимости позиций (с доходами за горизонт) относительно текущей стоимости, база покрытия — стоимость позиций |
| Виды снимка | `fx_rate` (курс пары), `price` (цена инструмента в его валюте за единицу) |
| Флаги | `factor_not_in_scenario:`, `fx_missing:` |

## Для плагина, который зависит от `market`

- `msa.plugins.market.fx`: `pair`, `requirement(currency, base)` (курс из снимка),
  `factor(currency, base)` (валютный фактор пары), `spot(prepared, ...)` (курс; `None`,
  если его нет — никогда не молчаливая единица), `log_change(scenario, ...)` (центральное
  значение и реализации шока пары).
- `msa.plugins.market.kinds`: константы `FX_RATE`, `PRICE`.

## Папка плагина

| Путь | Что там |
|---|---|
| `__init__.py` | объявление `plugin = Plugin(...)` |
| `fx.py` | курс и валютный фактор позиции в чужой валюте |
| `kinds.py` | виды снимка плагина |
| `tests/` | тесты плагина |

## Проверка

```powershell
uv run msa-plugin check market
uv run --frozen pytest src/msa/plugins/market
```
