# Как добавить тип инструмента

Тип инструмента теперь добавляется **плагином**: пакетом в `src/msa/plugins/<plugin_id>/`.
Прежний способ (класс `AssetModel` в `src/msa/assets/`) удалён вместе с этим пакетом.

Коротко:

```powershell
uv run msa-plugin new asset gold --label "Золото"   # шаблон, который сразу проходит проверку
uv run msa-plugin check gold                        # схемы, единицы, выходы, детерминизм, срезы
uv run msa-plugin demo-run gold                     # P5/P50/P95 по демо-кейсу
```

Плагин объявляет тип инструмента (схемы `terms` и `params`, форму редактора), модель
(`requirements` → `validate` → `calculate`), метрики, факторы сценария, вклад в срез
портфеля, вид результата, разделы отчёта и правила. Ядро не редактируется.

Подробное руководство: [plugins.md, раздел 3](plugins.md#3-новый-тип-инструмента-и-его-расчёт).
Примеры: `src/msa/plugins/equity` (акция, факторный стресс, FX) и `src/msa/plugins/credit`
(четыре кредитных семейства поверх Track A v3.2).

## Новое кредитное семейство

Кредитный плагин расширяется семейством: класс `CreditFamily` в
`plugins/credit/families/` объявляет типы, входы отчётности, ряды, метрики ковенантов и
помесячную модель; строка в `FAMILIES` (`families/__init__.py`) регистрирует его, и модель
семейства появляется в реестре. Факторы
`credit.*`, срез `credit.loss`, правила R1–R5 и калибровки PD семейство использует общие.
