## Порядок работы

1. Создайте портфель через интерфейс. Внесите данные на дату из задания, укажите источники. Недостающие сведения запросите у финансистов; если получить их не удалось, перечислите незаполненные поля.
2. Добавьте событие и опишите его силу. Числа в примерах сценариев уточните по источникам или с финансистами.
3. Оцените предложенный граф: верно ли он описывает влияние события на вашу компанию, что пропущено, какие связи лишние. Сохраните замечания, внесите исправления и запустите расчёт.
4. Сравните результат с фактическими показателями за указанный период.

Для исходных данных используйте отчётность и планы до события. Фактические результаты последующего периода нужны для сравнения.

## Что сдать

Ссылку на расчёт, граф с замечаниями и таблицу:

| Показатель | Оценка системы и диапазон | Факт, источник | Расхождение и его причина |
|---|---|---|---|
| … | … | … | … |

**Граф принимается**, если он учитывает способы влияния события, перечисленные в задании, а направление и сроки влияния соответствуют работе компании.

**Допуски для первого прогона:** 20% по суммам, 0,5 по коэффициентам покрытия, 5 п.п. по доходности акций, один месяц по срокам. Другие допуски зафиксируйте до расчёта. Укажите, какие оценки уложились в допуск, и разберите остальные.

По кредитам отдельно укажите ожидаемые потери системы и фактические просрочки и невозвраты.

Если данных для расчёта не хватило, сдайте собранные сведения и список пробелов.
